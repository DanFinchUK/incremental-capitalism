# incremental-capitalism

Play online at https://danfinchuk.github.io/incremental-capitalism/

A satirical British incremental game built with Vue 3, Pinia, Vite, and TypeScript.

## Development

```bash
npm install
npm run dev        # local dev server
npm test           # Vitest unit & component suite
npm run typecheck  # strict vue-tsc check
npm run build      # production build to dist/
```

Pushes to `main` automatically test, typecheck, build, and deploy `dist/` to `gh-pages`.
